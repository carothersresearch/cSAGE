# cSAGE
Code and supplemental data for manuscript Conjugation-based Serine Recombinase-Assisted Genome Engineering (cSAGE) Enables Bioproduction in Non-model Bacteria

The jupyter notebook `cSAGE_flux_calculations.ipynb` holds all code required to recreate the metabolic flux map in Figure 5. The base model used is from the article [System-level analysis of metabolic trade-offs during anaerobic photoheterotrophic growth in Rhodopseudomonas palustris](https://doi.org/10.1186/s12859-019-2844-z).
